## Baseline defects on record (dispositions, no silent fixes)

- **DEFECT-1 (blocks P1):** TWO files use non-raw `'\w'` regex
  strings inside `__main__` example blocks:
  - `softlab/tu/station/parameter.py:580-581`
  - `softlab/jin/validator/implements.py:470-471` (second file added
    per developer review; reproduction below confirms both fail
    identically under forced compile).
  Forced compile under `-W error` raises
  `SyntaxError: invalid escape sequence '\w'` in both files. Actual
  evidence recorded below. Disposition (agreed with sw-tom): fix as
  raw strings (`r'...'`) in the `__main__` example blocks of BOTH
  files in a dedicated commit — zero behavior change (example blocks
  only, not imported at runtime); the zero-warning gate cannot pass
  while these stand.
- **DEFECT-2:** `Parameter.__init__` warns when a parameter is
  neither settable nor gettable (`parameter.py:262-263`, noted in
  the TU-003 code review). This is a deliberate, documented warning
  on a programmer-error path; it does not fire anywhere in the suite
  (full `-W error` run is clean). Disposition: keep, and list under
  documented limitations (DC-1); not a gate blocker.
