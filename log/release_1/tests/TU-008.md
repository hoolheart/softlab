## Gate procedures (manual, recorded — not automated tests)

- **P1 — final compilation/regression check (principle 5).**
  Commands (from repository root, `.venv`, Python 3.13.15):
  1. `.venv/bin/python -W error -m compileall -q -f softlab tests`
     — must exit 0 with **zero errors/warnings** (forced recompile;

  2. `.venv/bin/python -W error -m unittest discover -s tests -p
     'test_*.py'` — all tests pass, zero warnings escalated.
  3. Import smoke under `warnings.simplefilter('error')`:
     `import softlab`; `from softlab.tu.station import ...`;
     `from softlab.tu.theory import ...`.
- **P2 — package-artifact inspection.**
  `build` is **not installed** in `.venv` at case definition
  (verified: `ModuleNotFoundError: No module named 'build'`).
  Recorded procedure (endorsed): install the backend into `.venv`
  itself — `python -m pip install build` — then run
  `python -m build` (isolated PEP 517 build, default behavior).
  If the isolated build environment cannot be created in the local
  toolchain, the recorded fallback is `python -m build --no-isolation`
  (build backend deps then resolved from `.venv`); any use of
  `--no-isolation` is recorded explicitly in the evidence section.
  Inspect `dist/`: sdist and wheel both contain `softlab/tu/station/*`
  and `softlab/tu/theory/*`, `softlab/VERSION.txt` is present in both
  artifacts, wheel metadata version equals `softlab.__version__`
  (0.3.0); artifacts built in a temporary directory, never committed.

## Baseline defects on record (dispositions, no silent fixes)

- **DEFECT-1 (blocks P1):** TWO files use non-raw `'\w'` regex
  strings inside `__main__` example blocks:
  - `softlab/tu/station/parameter.py:580-581`
  - `softlab/jin/validator/implements.py:470-471` (second file added
    per developer review; reproduction below confirms both fail
    identically under forced compile).
  Forced compile under `-W error` raises
  `SyntaxError: invalid escape sequence '\w'` in both files. Actual
  evidence recorded below. Disposition (agreed with sw-tom): fix as
  raw strings (`r'...'`) in the `__main__` example blocks of BOTH
  files in a dedicated commit — zero behavior change (example blocks
  only, not imported at runtime); the zero-warning gate cannot pass
  while these stand.
- **DEFECT-2:** `Parameter.__init__` warns when a parameter is
  neither settable nor gettable (`parameter.py:262-263`, noted in
  the TU-003 code review). This is a deliberate, documented warning
  on a programmer-error path; it does not fire anywhere in the suite
  (full `-W error` run is clean). Disposition: keep, and list under
  documented limitations (DC-1); not a gate blocker.
