## Design compliance

- **`Reading`** (parameter.py:96-141) is `@dataclass(frozen=True)`
  placed immediately before `Parameter`, with exactly the designed field
  set and order — probed directly:
  `['value', 'acquired_at', 'quality', 'error', 'uncertainty',
  'calibration']`. Attribute rebinding raises
  `dataclasses.FrozenInstanceError` (probed). `json.dumps` of a reading
  raises `TypeError` under the standard encoder (probed) — the explicit
  serialization limit, no `__iter__`/`to_json`/fallback of any kind.
  The mandated verbatim quality text ("``quality`` is a closed
  vocabulary: exactly ``'ok'`` (acquisition chain completed) or
  ``'failed'`` (acquisition chain raised). No other value is defined.")
  is present verbatim (line wraps only), as are the failed-read field
  states and the arch-review-observation sentence that the generated
  dataclass `__repr__`/`__hash__` touch field values. Exported from
  `softlab/tu/station/__init__.py` (one additive line);
  `softlab/tu/__init__.py` untouched.
- **`Parameter.read()`** (parameter.py:419-459) is the exact design
  pseudocode. The gettable pre-check sits **outside** the `try` and is
  **byte-identical** to `get()`'s check (parameter.py:411-412 vs
  449-450: same property, same `RuntimeError`, same f-string message).
  The `try` wraps the whole `self.get()` chain (permission check,
  `before_get`, encoder); `except Exception as error` only —
  `BaseException` propagates. Success stamps `acquired_at=time.time()`
  after `get()` returns; failure returns `value=None`,
  `acquired_at=None`, the original exception object on `error`, and
  declared `uncertainty`/`calibration` still populated. No caching —
  each call acquires afresh. Both mandated verbatim docstring texts
  (permission path and failure path) are present verbatim. **`get()` is
  untouched byte-for-byte** (no diff hunk reaches it), so legacy
  value-only semantics, acquisition counts and exception propagation
  are preserved by construction.
- **Six constructor keywords** (parameter.py:213-219) are appended
  after `before_get`, preserving positional compatibility, with
  exactly the designed types and `None` defaults. They are stored
  verbatim (`self._unit` … `self._calibration`, parameter.py:282-289)
  **after** the `init_value` block — pure field assignments, no
  validation, no copying — so OBS-004 is respected and untouched.
  Probed flow-through: `VisaParameter(..., unit='V', value_type=
  'float', shape=[1], channel='2', uncertainty=0.01, calibration=
  'cal-x')` composes through the existing `**kwargs` chain with **zero
  VISA signature changes** (`visa.py` not in the diff); the declared
  metadata reaches both `describe_reading()` and `Reading`. Declared
  metadata is echoed by reference (probed: `read().uncertainty is u`).
  `QuantizedParameter` and `ProxyParameter.__init__` correctly gain no
  keywords.
- **`describe_reading()`** (parameter.py:368-395) returns a fresh dict
  literal per call (probed: equal but not identical across calls) with
  exactly the six designed fields in its own `schema_version` 1
  namespace, touching only `self._name` and the declared fields — zero
  I/O, never reads the value, never invokes validators/codecs/hooks or
  `str`/`repr` (case 6's opaque-value case is green). The mandated
  side-effect guarantee sentence is present verbatim. `describe()` v1
  untouched (case 4 green).
- **`ProxyParameter.read()`** (parameter.py:554-567) is the one-line
  forward `return self._obj.read()` returning the target's own
  `Reading` object — value/quality/error parity automatic, permission
  parity via the construction-time `gettable` copy plus the target's
  own pre-check, no proxy-side acquisition. No JSON fallback; no
  copying anywhere on the value path (case 6 `assertIs` green).
- **Docstrings.** `Parameter.__init__` documents the six keywords with
  `None` defaults and the no-validation/no-copying/read-only posture;
  the `Parameter` class docstring `Public methods:` list gains `read`
  and `describe_reading` marked as the opt-in measurement path distinct
  from legacy `get()`/`__call__`. No other docstrings changed.
- **Style and dependencies.** Line-length scan of the added lines: none
