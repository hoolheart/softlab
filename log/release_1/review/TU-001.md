## Required corrections

1. **Medium — Ordered settings are claimed but untested.**
   `log/release_1/compatibility.md` lists ordered settings under
   `nested_paths_delegation_ownership_and_removal`. In
   `tests/test_tu_contracts.py`, the only `set_parameters` call contains one
   item, so it cannot detect a change in sequence order. Add two parameters
   with recording set hooks, set them through a sequence in a known order, and
   assert the observed order. Preserve the existing nested path and removal
   assertions.

2. **Medium — VISA timeout configuration lacks a characterization assertion.**
   TU-001's acceptance criterion in `log/release_1/prd.md` explicitly includes
   VISA timeouts. `test_eager_open_clear_and_transport_errors` passes `0.1` as
   a `query` delay and asserts exception identity; it does not check the
   `VisaHandle.timeout` property or forwarding to the resource. Add a mock-only
   assertion for the existing constructor/default and setter/getter behavior,
   and label the numeric units as the unresolved OBS-001 discrepancy. This
   should record current behavior without declaring the seconds/milliseconds
   mismatch desirable or changing production code.
