## Design compliance

- Public surface matches: `describe(metadata=None)` on all three classes
  returns common fields (`schema_version: 1` as int, `name`, qualified
  `module.qualname` type string, `metadata`); parameter adds
  `settable`/`gettable`; device adds `parameters`/`children` keyed by lookup
  key; station adds `devices` keyed by lookup key. The contained object's
  current name is serialized separately from its lookup key (verified by the
  renamed-parameter acceptance case and by inspection of
  `_describe_device_node`).
- No-I/O guarantee holds: traversal reads `_parameters`, `_devices`, `_name`,
  `_settable`, `_gettable` directly; it never calls `get`, `set`, `snapshot`,
  validators, codecs, hooks, or VISA handles, and never uses delegated
  attribute lookup. Nested nodes are constructed inline, so subclass
  `describe()` overrides are never invoked during traversal, matching the
  corrected version-1 contract.
- Metadata contract matches: exact built-in types only, `bool` checked before
  `int`, exact `str` keys, `math.isfinite` for floats, `TypeError` for
  unsupported types/keys versus `ValueError` for non-finite floats and cycles,
  path-annotated messages that format only safe key/index text and the type
  name (never the unsupported value), recursive detachment, per-occurrence
  copying of shared acyclic containers, and no partial publication on failure
  (validation precedes node construction; exceptions propagate before any
  result is returned).
- Cycle policy matches: device identities are tracked on the active ancestry
  path only (`active.add`/`discard` around descent); revisiting an active
  device raises `ValueError` carrying the lookup path; acyclic shared reuse
  yields independent nodes; parameters are leaves; metadata recursion uses its
  own active set. Fresh active sets per station top-level device are correct:
  a cycle through a device is necessarily reachable within that device's own
  traversal.
- Dependencies: stdlib `math` (already imported) and `typing` only; no new
  runtime dependency. English docstrings in the surrounding Args/Returns/
  Errors/Side-effects style; type annotations present; all lines within the
  80-column Black width; no syntax beyond py39.

## Compatibility

No existing constructor, `snapshot()` shape, permission, hook, import path, or
lookup behavior is modified; the diff is purely additive. A parameter or child
named `describe` collides with the new method through delegation, but this is
the pre-existing OBS-006 pattern (delegated names may collide with methods);
explicit lookup remains available and unchanged. I verified such a parameter
remains reachable at its lookup key in the description output.

## Review issues and closure

No issues found. Independent spot checks beyond the acceptance tests
confirmed: `enum.IntEnum` values and `str` subclass keys are rejected with
`TypeError`; a shared acyclic list under two metadata keys is copied
independently per occurrence; device-cycle messages carry the lookup path
(e.g. `root.child.root`) from both device and station entry points; the
unsupported-type message names the type, not the value.
